# Pro Camera

Камера для Android, которая сразу открывается в профессиональном (ручном) режиме фото.

## Возможности

- **PRO-режим при запуске**: ISO, выдержка, ручной фокус, баланс белого (пресеты и Кельвины), экспокоррекция (EV).
- **Кнопка «АВТО»** возвращает всё в автоматический режим. Если все параметры уже автоматические, она подсвечена жёлтым.
- **Настройки сохраняются**: ручные параметры, вспышка, таймер, формат кадра, сетка и выбранная камера с объективом восстанавливаются при следующем запуске.
- **Формат кадра**: 4:3 или во весь экран. Во весь экран видоискатель занимает весь телефон, а снимок получается в пропорциях экрана, например 20:9.
- **Объективы**: кнопки 0.6x, 1x, 2x переключают камеры телефона. Если телефон отдаёт приложению только одну камеру, эти кнопки управляют зумом.
- **Видео**: кнопка «Видео» переключает в режим записи, и на её месте появляется кнопка «Фото» для возврата. Запись идёт со звуком и таймером.
- **Галерея**: показывает фото и видео из `DCIM/Camera`, той же папки, куда сохраняет стандартная камера. Снимки видны и в обычной галерее телефона.
- **Передняя и задняя камера** переключаются одной кнопкой.
- В режиме автофокуса можно коснуться экрана, чтобы сфокусироваться. В видоискателе есть сетка, а у фото правильная ориентация при съёмке горизонтально.
- В авто-режиме на кнопках ISO и выдержки видно, какие значения выбрала автоматика.

## Установка APK

1. Откройте вкладку **Releases** этого репозитория на телефоне.
2. Скачайте `ProCamera.apk` из последней сборки.
3. Откройте файл и разрешите установку из неизвестных источников.

APK собирается автоматически в GitHub Actions при каждом push в `main`. Его также можно скачать во вкладке Actions, в артефакте `ProCamera-apk`.

## Сборка вручную

Нужны JDK 17, Android SDK и Gradle 8.9:

```bash
gradle assembleDebug
```

Можно также открыть проект в Android Studio.

## Ограничения

- Ручные ISO и выдержка работают только на камерах с поддержкой Camera2 `MANUAL_SENSOR`. На камерах уровня LEGACY эти параметры недоступны, и приложение показывает об этом сообщение.
- Режим «Кельвин» требует `MANUAL_POST_PROCESSING`. Без этой поддержки выбирается ближайший пресет.
- APK подписан debug-ключом. CI создаёт его при первой сборке и сохраняет как `app/debug.keystore`, поэтому новые версии ставятся поверх старых. Для публикации в Google Play нужен свой release-ключ.

## Технологии

Kotlin, Jetpack Compose, CameraX 1.3 с Camera2 Interop, MediaStore, Coil.
